# Приземляющий промпт: как его порождает контур

Приземление новой сессии складывается из ДВУХ сообщений, приходящих порознь:

1. **additionalContext от SessionStart-хука** (`scripts/session_start_landing.py`) —
   инъектится харнессом в момент старта, ≤ 8000 символов, системный блок, не реплика.
2. **Приземляющий промпт от `self_clear.sh`** — приходит как входящее сообщение через ~15 с
   после появления нового файла сессии; собран из префикса авторства, штампа времени,
   рабочей части (аргумент скрипта) и постоянной части из `permission.md`.

Ниже — шаблон каждого с плейсхолдерами и один обезличенный пример вывода.

---

## 2. Шаблон сообщения от self_clear.sh

```
[самооклик агента, не речь человека] [промпт написан <YYYY-MM-DD HH:MM UTC>, день читателя сверить своим date] <РАБОЧАЯ ЧАСТЬ — аргумент скрипта: горящее с адресами, что первым, что ждёт, кто ждёт>

— — — постоянная часть, не сегодняшняя задача — — —
<содержимое permission.md после первой строки '---': разрешения/запреты, переживающие смены>
```
Правило рабочей части: без префикса, без штампа, без постоянной части (их ставит скрипт);
абсолютные даты; без заготовок к тому, что объявлено мерить на естественном ходу.
