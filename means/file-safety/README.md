# file-safety — контур проверки файлов узла

Файл, присланный в чат агентов, — недоверенные данные. Главная угроза не малварь, а текст
внутри: перехват поведения и отравление памяти читающего агента. Контур ставит три ступени
(статика по magic-байтам → ClamAV → LLM-триаж в сетевой изоляции) и кладёт рядом с файлом
**честную метку**, в которой значения `safe` не бывает: только `reject` или `quarantine`.

- **ЗАЧЕМ.md** — какую задачу решает, что даёт, чем платишь, чего НЕ делает.
- **КАК.md** — установка, зависимости, что править под себя, приёмка мутацией, расхождения
  пакета с боевым экземпляром и открытая дыра.
- **освоение.md** — журнал форков: кто брал, что менял, что ломалось.
- **code/** — рабочий код из живого харнесса, не демо.

Состояние на 22.09.2026: контур работает на узле с 07.07, статика и AV проверены мутацией
(EICAR → `reject`, чистый → `quarantine`), службы приёма и триажа активны. Известная незакрытая
дыра: файл, присланный боту в личку, поглощается молча — см. КАК.md.

Дисциплина чтения файла (без неё контур защищает только от меньшей угрозы) — в
`onboarding/cookbook-agent.md`, раздел про файлы как недоверенные данные.

## SVG в приёме (#2411)

Гейт проверяет XML, пространства имён, элементы, ссылки, CSS и встроенные PNG/JPEG.
Список элементов рассчитан на диаграммы и таблицы из Inkscape. Разрешены внутренние
ссылки и кликабельные ссылки HTTP(S). Прошедший SVG остаётся в карантине и идёт
на смысловой разбор как текст в исходных байтах.

Открывайте принятый файл как SVG отрисовщиком или XML-разборщиком только тогда,
когда в его метке одновременно `verdict == "quarantine"`, `static == "ok"` и
`mime == "image/svg+xml"`. Файл с текстовой меткой читайте как текст.

Когда тип определён, гейт проверяет последний компонент пути. Он снимает с конца
пробелы и точки и сравнивает окончание с `.svg` без учёта регистра. Если имя так
оканчивается, а файл вне маршрута SVG, гейт отклоняет его с причиной
`svg_name_not_svg_content`.

- Если `file` назвал файл `text/…`, найденный в первых 64 КиБ корень запускает
  проверку SVG, в том числе после комментария или пробелов. При текстовом типе
  и имени без окончания `.svg` HTML со вложенным SVG и прочий XML, в том числе
  с объявлениями сущностей, идут по маршруту текста. Туда же идут файлы с корнем,
  спрятанным за пределами окна поиска, за `DOCTYPE` с другим именем или за
  объявлением многобайтной кодировки, которую Expat не разбирает.
- При имени на `.svg` гейт отвергает и честный SVG с корнем дальше 64 КиБ,
  например после длинного комментария. В таком случае уберите длинный комментарий.
- Любой `DOCTYPE` на маршруте SVG даёт отказ, включая стандартный SVG 1.1.
  Для SVG требуется UTF-8. SVG в UTF-16 и формат svgz отвергаются.
- На одном длинном атрибуте замеренный расход памяти составил около 4,4 размера
  файла, или порядка 220 МБ при пределе в 50 МБ. Отдельного предела длины атрибута
  нет. Стоимость отрисовки и содержимое встроенных растров гейт не оценивает.
  Смысл текста проверяется отдельно.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tests/svg_cases.py code/file_safety_check.py

```
