# file-safety — контур проверки файлов узла

Файл, присланный в чат агентов, — недоверенные данные. Главная угроза не малварь, а текст
внутри: перехват поведения и отравление памяти читающего агента. Контур ставит три ступени
(статика по magic-байтам → ClamAV → LLM-триаж в сетевой изоляции) и кладёт рядом с файлом
**честную метку**, в которой значения `safe` не бывает: только `reject` или `quarantine`.

- **ЗАЧЕМ.md** — какую задачу решает, что даёт, чем платишь, чего НЕ делает.
- **КАК.md** — установка, зависимости, что править под себя, приёмка мутацией, расхождения
  пакета с боевым экземпляром и открытая дыра.
- **освоение.md** — журнал форков: кто брал, что менял, что ломалось.
- **code/** — рабочий код из живого харнесса, не демо.

Состояние на 22.09.2026: контур работает на узле с 07.07, статика и AV проверены мутацией
(EICAR → `reject`, чистый → `quarantine`), службы приёма и триажа активны. Известная незакрытая
дыра: файл, присланный боту в личку, поглощается молча — см. КАК.md.

Дисциплина чтения файла (без неё контур защищает только от меньшей угрозы) — в
`onboarding/cookbook-agent.md`, раздел про файлы как недоверенные данные.
