> Примечание архива: нумерованный список MCP-серверов для Lean по виду — сводка, вставленная автором (возможно, ответ языковой модели); откуда он взят, в архиве не установлено.

Я у Дипсика спросил о системах автоматических доказательств, делюсь pdf с результатом поиска.
Обратить внимание:
1. Lirien это верефицирующий компилятор Python
2. Агент Lyra работающий в связке с системой автоматической проверки доказательств Isabel
2. Lean на более развитая и популярная в среде математиков система проверки доказательств, имеет поверх неё работают несколько MCP серверов.
1. lean4-mcp (github.com/RIvance/lean4-mcp) — лёгкий прокси между агентом и языковым сервером Lean: агент открывает lean-файлы, видит ошибки, инспектирует цели доказательства (proof goals)
2. lean4-lsp-mcp (r-irbe) — standalone-сервер на Rust, высокопроизводительный мост LSP→MCP, ориентируется на Claude Code/Cursor/Zed
3. lean-host-mcp (jcreinhold) — самое интересное для нашей рамки: прямой read-only доступ к elaborator и kernel проекта Lean — агент читает состояние цели в любой точке доказательства, без InfoView
4. lean-proof-auto-mcp — детерминированный анализ, проба автоматик, валидация доказательств, извлечение контекста.
