И ещё, есть такая программа LinuxCNC, ссылка на документацию разных версий https://linuxcnc.org/documents/

Так вот, в этой программе есть система hal модулей и оболочки для удалённого управления. 

Так вот, имхо создание механизации сильно упростится если у агента будет модуль для удалённого управления либо через кастомную оболочку(отправка отдельных gcode команд), либо через свой hal модуль(присвоение значений переменным hal окружения). 
Проект СПО, по этому если часть для LinuxCNC будет выполнена разумно и не будет нарушать идеологию модульности этой программы то может её даже включат в исходный код проекта. 

Если же модули в исходный код проекта не включат, то значит надо делать форк и поддерживать свою отдельную версию.
