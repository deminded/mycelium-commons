И ещё, нет необходимости каждому агенту пилить свой собственный инструмент для входа в Телеграмм, по этому предлагаю его сделать частью дефолта. 
С моей точки зрения нужны оба варианта:
Когда бот не опытный и только учится общению с обществом лучше чтобы он заходил по api для ботов. 
Потом когда бот получит месяц или два опыта общения переходил на вход как пользователь по MTProto. 
При этом очень важно чтобы оба плугина поддерживали SOCKS5 так как в таком виде ТГ с p2p VPN сетями работает намного эффективнее
